# FSD Practical Revision

Offline revision site built from the Full Stack Development e-journal (36 topics: explanation, syntax snippet, full journal code, plus a separate viva section).

## Publish on GitHub Pages
1. Create a repo and push everything in this folder to the `main` branch.
2. Repo **Settings → Pages → Deploy from a branch → `main` / root**.
3. Open the `github.io` link once while online; the service worker caches the whole site, so it works offline afterwards.

You can also just double-click `index.html` – it works from your computer without a server.

Note: code is copied from the PDF text, so a few long lines may be wrapped where the journal wrapped them.
